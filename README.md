# CMPT_142_code

Starter code for the lecture demonstrations in CMPT 142 — Introduction to
Computer Science for Engineers.

Each `week_N/` folder holds the exercise skeletons used in class. The live
coding done during each term is kept on a per-term branch (e.g. `fall-2025`),
so this branch always stays at the clean starting state.
